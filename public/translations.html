Translating Z Pass

We've worked hard to make Z Pass's English version as smooth as possible in terms of language. Now we're looking for equally smooth translations into the rest of the world's languages. If you're a linguist, pro translator or language geek and would like to help us get closer to perfection, you've come to the right place.

Start Translating

The Interface

To get started, simply log in, find a phrase in your language that you can improve and suggest a new translation – or vote for an existing suggestion. As soon as your suggestions are reviewed and accepted, the new phrases become immediately available in Z Pass apps, no updates required.

Official Translations

We're gradually expanding the list of languages available to all users from the “Language” menu in their apps.

Style Guide

We think a good translation should be:

1. Consistent

The same things need to have the same names everywhere. Not just within one app, but also on all platforms. Z Pass features should have the same names on Android, iOS, Windows and macOS.

2. Natural

You don't have to always stick to the English original. Sometimes it makes more sense to simply describe what the app does in your own language.

3. Default

It will be much easier for users to use Z Pass if familiar concepts have familiar names here.

4. Beautiful

Use good language that would make the app look as if it was built in your region. Respect your language's grammar and style where possible.

5. And it MUST FIT

This last one is never easy. Text is inseparable from design. Everything must fit into its allotted space.
