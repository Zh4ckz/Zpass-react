Protect your token

Keep tokens on a trusted server. Do not commit them to source control, share them in chat or embed them in a public website or mobile app.

Service status

The site is hosted on Firebase and does not depend on a PC being left on. Bot creation and API methods still need the serverless gateway deployment to become available.
