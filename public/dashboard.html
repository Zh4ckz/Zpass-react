Unlock cloud vault

Your recovery password is processed on your device and is never sent to the server. If you've turned on the Authenticator code in the app, that's used instead — this password is for older vaults or when the code is turned off.
✉

Reset recovery password

This sends a verification link to your account email. Clicking it proves the request is really you, then lets you set a brand-new recovery password.

Important: your existing encrypted vault items were locked with the old recovery password and cannot be decrypted with a new one — resetting starts a fresh, empty vault. If you still might remember the old password, cancel and keep trying it instead.
lock.png

Code required to unlock vault

Open the PassGram app on your phone → Authenticator → enter the 6-digit code from the zpass.web.app card at the top. This code both verifies your identity and unlocks your encrypted vault; it's never sent to the server.
