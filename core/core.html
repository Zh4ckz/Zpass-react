Z Pass Core API & Protocols

Welcome to Z Pass Core Specification. Here you will find developer documentation for the MTProto binary protocol, TL Schema definitions, and end-to-end encrypted messaging channels.

1. Client API Overview

The Z Pass API allows developers to build custom messaging clients, desktop applications, and automated bots. Communication is secured via MTProto encryption layer.

2. MTProto 2.0 Encryption Protocol

MTProto 2.0 provides high-speed binary serialization over TCP and HTTPS with Diffie-Hellman key exchange and AES-256-IGE payload encryption.

// DH Key Exchange & Encrypted Frame Structure
auth_key_id:int64 msg_key:int128 encrypted_data:bytes

3. Type Language (TL) Schema

Z Pass schemas are defined in Type Language syntax:

user#2e2e12a id:long first_name:string username:string = User;
message#8d8d21c id:long sender_id:long text:string date:int = Message;
