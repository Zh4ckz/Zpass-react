Developer Documentation

Build Telegram-compatible bots, custom messaging tools, and Python / Node.js / PHP integrations using the PassGram SDKs and HTTP REST API.

1. Quickstart & Bot Token

To start building, obtain a Bot Token from @Zbot inside the Z Pass app or web app. Your bot token format looks like: 123456789:ABCdefGHIjklMNOpqrsTUVwxyZ.

2. Python Integration (pip install passgram)

Install the official PassGram Python package using pip:

pip install passgram

Example Python bot script:

from passgram import ZpassBot

bot = ZpassBot(token="123456789:YOUR_BOT_TOKEN")

@bot.on_message()
def handle_message(message):
    if message.text == "/start":
        bot.send_message(message.chat.id, "Hello from PassGram Python Bot!")

bot.run()

3. Node.js Integration (npm install passgram)

Install the Node.js SDK:

npm install passgram

Example Node.js bot script:

import { ZpassBot } from 'passgram';

const bot = new ZpassBot({ token: '123456789:YOUR_BOT_TOKEN' });

bot.on('message', (msg) => {
  if (msg.text === '/start') {
    bot.sendMessage(msg.chat.id, 'Hello from PassGram Node.js Bot!');
  }
});

bot.start();

4. PHP Integration (composer require passgram/bot)

Install via Composer:

composer require passgram/bot
<?php
require 'vendor/autoload.php';

use PassGram\ZpassBot;

$bot = new ZpassBot('123456789:YOUR_BOT_TOKEN');
$bot->sendMessage([
    'chat_id' => $chatId,
    'text' => 'Hello from PHP SDK!'
]);

5. HTTP & JSON REST API

Send JSON requests over HTTPS:

POST /bot<token>/sendMessage
Content-Type: application/json

{
  "chat_id": "123456789",
  "text": "Hello from Z Pass REST API"
}
